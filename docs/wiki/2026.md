# 2026년

기록용.

**요즘 사용하는 AI 도구**

- [Gemini](/docs/wiki/google-gemini.md)는 모델 업데이트가 정체되어 사실상 사용하지 않는다.
- [Copilot](/docs/wiki/github.md#github-copilot)는 구독 해지했다.
  [Models를 더 이상 제공하지 않기 때문이다.](/docs/wiki/github.md#github-models)
- [Claude Code](/docs/wiki/anthropic.md#claude-code)
    - MCP는 반짝했다가, 로컬 서버 보다는 리모트 서버로써 많이 활용된다. cli 등 대체는 많다지만 프로토콜로써 가치가 있다.
    - Skills, Subagent는 유용하나 모델 성능이 좋아지면서 간단한 지침만으로도 잘 동작한다.
    - Teammates는 큰 규모의 작업에 유용하다. 선택이 많아서 짧은 흐름으로 여러번 작업하는 경우가 그렇다.

**OSS 종료 프로젝트**

눈에 띄는 프로젝트의 종료가 있었으나..

[Localstack](/docs/wiki/aws.md#localstack)는 3월에 무료 소프트웨어 라이센스를 폐기하며, 오픈 소스 버전을 아카이브 했다.
로컬 개발 환경의 AWS 모의로써 마지막 버전에서도 유효하다.

[nvim-treesitter](/docs/wiki/vim.md#구문-강조)는 4월에 아카이브 하였으나, 다행히 7월에 다시 복귀했다.
nvim-treesitter는 neovim에 자연스럽게 흡수되고 있지만, 아직은 모자란 부분이 많다. 특히 파서 추가하는 부분.
파서로써 nvim-treesitter의 사용은 유효하다. nvim-treesitter-textobjects 또한 커스터마이징하는데 유용하다.

**터미널 에뮬레이터 변경**

주로 사용하는 맥 터미널 에뮬레이터를 iTerm2에서 [WezTerm](/docs/wiki/mac-os.md#터미널에서-한글을-두-번-입력해야-하는-문제)으로 바꿨다.
기본앱, kitty, iTerm2 모두 한글 조합 중에 엔터를 두 번 눌러야 조합완성 후 입력까지 되는 문제가 있는데,
WezTerm은 조합 중에 입력까지 한 번에 되는 유일한 터미널 에뮬레이터였다.
